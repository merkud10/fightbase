# Время завершения боя: исправление импорта ESPN

Дата проверки: 1 ноября 2026, Москва.

## Подтверждение

Официальная история https://www.ufc.com/athlete/damian-pinas показывает победы над Пуляевым (R1, 1:15) и Алмейдой (R1, 4:44). Рекорд 11-1-0 совпадает с FightBase. Проверено через браузер; даты UFC в текущем региональном представлении могут отличаться от местного дня события.

Прямой read-only запрос первичного API ESPN подтвердил:

| API | Бой | status.clock | status.displayClock | completed |
|---|---|---:|---|---|
| https://site.api.espn.com/apis/site/v2/sports/mma/ufc/scoreboard?dates=20261003 | Pinas / Pulyaev | 75 | 1:15 | true |
| https://site.api.espn.com/apis/site/v2/sports/mma/ufc/scoreboard?dates=20260711 | Pinas / Almeida | 284 | 4:44 | true |

В FighterRecentFight время уже правильное. В Fight.resultTime были 3:45 и 0:16. Причина найдена в scripts/sync-event-fights.js: завершённый clock ошибочно вычитался из 300. Это обратное время, а не время завершения. Исторический синк профилей использует displayClock напрямую и такой ошибки не содержит.

## Изменение

Парсер завершённых боёв теперь использует валидный displayClock, при его отсутствии — числовой clock без вычитания. Незавершённый бой, отсутствующее/некорректное время возвращают null. Диапазон для текущего UFC-синка — 0:00–5:00. Вызов парсера для судейского решения не менялся.

Отдельный scripts/repair-pinas-result-times.js по умолчанию работает как dry-run. --apply меняет только resultTime двух проверенных боёв; проверяются ID, участники, турнир, победитель, метод, раунд и старое время. Резервная копия создаётся до транзакции; updatedAt защищает от конкурентной записи; повторное применение — no-op. Остальные старые результаты требуют отдельного аудита, массовое обращение времени не выполняется.

Четыре теста покрывают реальные пары значений ESPN, границы, невалидные/отсутствующие данные, live-состояние и защиту исторической правки. Проверка синтаксиса импортёра и git diff --check прошли.

Дополнительно сверён https://www.ufc.com/athlete/farid-basharat: рекорд 16-0-0 и последний соперник John Garza совпадают после предыдущего исправления. Статус UFC «не выступает» не приравнивается автоматически к завершению карьеры: в схеме нет отдельного статуса ухода из организации. Значение active не менялось на retired. Английская биография Пинаса содержит старый рекорд 10-1-0; отдельная публичная EN-версия сейчас перенаправляется на RU, редактура этого поля остаётся в очереди.

# Турнир → разбор → следующий материал

Проверка 31 октября 2026, исходная версия `28c7fce`.

Подтверждено в браузере: `/ru/events/ufc-335-oliveira-vs-lopes` содержит ссылки «Разбор боя» в строках. Переход к Оливейра — Лопес открывает страницу с блоком «Другие прогнозы» на оставшиеся пять боёв и ссылкой обратно на весь кард.

Подтверждён дефект: в таблице завершённого `/ru/events/ufc-333-volkanovski-vs-evloev` нет ни одной ссылки на разбор, хотя прогнозы существуют. Причина в `app/events/[slug]/page.tsx`: ссылка находилась только в ветке незавершённого боя. Боковые быстрые ссылки ограничены шестью боями и на мобильной раскладке находятся после полного карда, поэтому не заменяют переход из каждой строки.

Исправление: ссылка выводится независимо от результата, если есть snapshot и непустой slug. Это сохраняет доступ к разбору для побед, ничьих и боёв без победителя. Дополнительно быстрые ссылки не формируются для пустого slug. Для ширины до 640 px ссылки в строке имеют отдельную область высотой минимум 44 px.

Локально: typecheck и 12 существующих тестов карточек/пиков/результатов прошли, diff проверен. Эти тесты проверяют логику данных, а не новый JSX. Окончательная проверка ссылок выполняется на production после деплоя. Новый браузерный тест на физическом телефоне не проводился; мобильное правило проверено по CSS. Спортивные факты и даты в этом проходе не сверялись с первичными источниками.

Отдельные цели переходов «турнир → разбор» и «разбор → другой разбор» ещё не настроены. Рост глубины посещения и поискового трафика после изменения пока не измерен.

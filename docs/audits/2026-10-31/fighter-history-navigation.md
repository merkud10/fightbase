# Профиль → завершённый бой

31 октября 2026. Продолжение работы по запросам о последних боях из search-queries.md.

В карточках истории профиля добавлены ссылки «Кард и результаты турнира» и «Разбор боя» (RU/EN). Сопоставление требует разрешённого профиля соперника, завершённого боя и совпадения календарной даты UTC. При нескольких совпадениях ссылки не выводятся. Разбор доступен только при наличии snapshot и slug. Высота ссылок не менее 44 px, строка переносится.

Используется существующая выборка до 50 боёв профиля; дополнительных запросов на каждую карточку нет. Несовпадение дня из-за часовых поясов намеренно оставляет карточку без ссылки. Рекорды, результаты, биографии и даты в базе не менялись. Новые цели Метрики и внутренние UTM не добавлялись.

Read-only проверка production до изменения подтвердила доступные разборы последних боёв Мэлотта, Стила и Доусона. У Башарата обнаружены различия соперника и даты между историей и структурированным боем: автоматическое сопоставление не применяется. Само наличие записи в базе не является независимым подтверждением спортивного факта.

Попытка сверить биографии по официальным страницам UFC Мэлотта и Доусона через веб-инструмент получила HTTP 403. Фактологическая редактура отложена до доступной первичной проверки; поисковые сниппеты не использованы для обновления профилей.

Локально: typecheck и 6 тестов сопоставления истории/имён прошли, git diff --check без ошибок. Тесты покрывают обе позиции бойца, другой день/соперника, незавершённый бой, дубли, неразрешённое имя и отсутствие разбора.
